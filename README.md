# MySQL Practice

Данный репозиторий содержит SQL-запросы для тестирования веб-приложения **Social Center** — системы социального обслуживания населения.

База данных включает в себя управление клиентами, заявками, услугами, отзывами, чатами с ботом и отчётностью.

### Что демонстрирует репозиторий:

* Глубокое владение SQL (JOIN, подзапросы, Window Functions)
* Навыки **Data Quality Assurance** и поиска багов
* Проверку бизнес-правил и целостности данных
* Подготовку аналитических отчётов

---

## Структура репозитория

```text
├── dump/
│   └── dump.sql                         # Дамп базы данных
│
├── queries/
│   ├── core_testing_queries.sql        # Основные запросы тестировщика
│   ├── data_integrity_and_quality.sql  # Проверка целостности и качества данных
│   └── business_rules_and_analytics.sql # Бизнес-правила и аналитика
│
└── README.md
```

| Файл                                           | Описание                                                                       |
| ---------------------------------------------- | ------------------------------------------------------------------------------ |
| **`queries/core_testing_queries.sql`**         | Основные запросы тестировщика: выборки, JOIN-ы, фильтрация, пагинация          |
| **`queries/data_integrity_and_quality.sql`**   | Проверка целостности данных, поиск "сиротских" записей, дубликатов и аномалий  |
| **`queries/business_rules_and_analytics.sql`** | Проверка бизнес-логики, статистика, аналитика и использование Window Functions |
| **`dump/dump.sql`**                            | SQL-дамп базы данных для восстановления структуры и данных                     |

## Ключевые навыки, которые демонстрируются

### Основной функционал

* Сложные `JOIN` (включая многотабличные)
* Работа с `NULL` (`IS NULL`, `COALESCE`)
* `GROUP BY`, агрегатные функции и `HAVING`

### Продвинутый уровень

* Коррелированные и некоррелированные **подзапросы**
* `EXISTS` / `NOT EXISTS`
* **Window Functions** (`ROW_NUMBER`, `LAG`, `RANK`)

### QA & Тестирование

* Поиск нарушений ссылочной целостности
* Выявление дубликатов
* Проверка бизнес-правил
* Анализ аномалий в данных
* Подготовка диагностических отчётов

---

## Как использовать

1. Восстановить базу данных из `dump/dump.sql`
2. Открыть файлы из директории `queries/` в любом SQL-клиенте (MySQL Workbench, DBeaver, DataGrip и т.д.)
3. Подключиться к базе данных `social_center`
4. Выполнять запросы из соответствующих файлов

### Восстановление базы данных

Дамп можно импортировать через MySQL Workbench, DBeaver или другой SQL-клиент.

Также восстановление можно выполнить через консоль:

```bash
mysql -u root -p < dump/dump.sql
```
